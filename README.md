# 🕊️ PeaceMirorBot (Бот-Миротворец для Telegram)

**PeaceMirorBot** — Telegram-бот для автоматического урегулирования конфликтов в группах, предотвращения ссор, фильтрации мата и оскорблений с помощью системы предупреждений и временных **мутов (режима чтения)**.

---

## 🌟 Ключевые возможности

1. **Эскалация наказаний (Mute Ladder)**:
   - **1-е нарушение**: Предупреждение в чате с призывом к мирному общению.
   - **2-е нарушение**: Удаление сообщения + **Мут на 15 минут** (режим чтения).
   - **3-е нарушение**: Удаление сообщения + **Мут на 2 часа**.
   - **4-е и далее**: Удаление сообщения + **Мут на 24 часа**.
2. **Умный детектор мата и обхода фильтров**:
   - Автоматическая нормализация латиницы, похожих символов и leet-speak (`cuka` -> `сука`, `xyp` -> `хур`).
   - Сворачивание повторяющихся букв (`хххуууй` -> `хуй`).
   - Поддержка динамического кастомного стоп-листа слов из БД (`/addword`, `/removeword`, `/wordlist`).
3. **Миротворческие инструменты**:
   - Команда `/report` (ответом на сообщение) для быстрого вызова админов к разгорающемуся конфликту.
   - Команда `/rules` — памятка правил мирного общения.
   - Команда `/mystats` — просмотр своей истории предупреждений.
4. **Фоновая автоматика**:
   - Автоматическое восстановление прав пользователя в чате после окончания срока мута.
   - Сброс устаревших предупреждений через 7 дней вежливого поведения.

## 🛠️ Команды бота

### Для участников:
- `/start` — Приветствие и описание бота.
- `/help` — Справка по командам.
- `/rules` — Правила мирного общения в чате.
- `/mystats` — Просмотр своей статистики нарушений и статуса мута.
- `/report` — *(ответом на сообщение)* Отправить жалобу администраторам на ссору или оскорбление.

### Для администраторов:
- `/mute <минуты> <причина>` — *(ответом на сообщение)* Выдать мут участнику на указанное время.
- `/unmute` — *(ответом на сообщение)* Снять мут с участника.
- `/warn <причина>` — *(ответом на сообщение)* Выдать предупреждение.
- `/addword <слово>` — Добавить слово в стоп-лист.
- `/removeword <слово>` — Удалить слово из стоп-листа.
- `/wordlist` — Показать кастомный стоп-лист.
- `/resetstats` — *(ответом на сообщение)* Сбросить нарушения пользователя.

## 🚀 Быстрый запуск

### 1. Требования
- Python 3.11+
- Зависимости: `python-telegram-bot[job-queue]`, `aiosqlite`, `python-dotenv`.

### 2. Настройка `.env`
Создайте файл `.env` (на основе `.env.example`):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=123456789
DB_PATH=peacemirror_database.db
MUTE_STEP_2_MINUTES=15
MUTE_STEP_3_MINUTES=120
MUTE_STEP_4_MINUTES=1440
RESET_INACTIVE_DAYS=7
```

### 3. Локальный запуск
```bash
pip install -r requirements.txt
python bot.py
```

### 4. Запуск в Docker
```bash
docker build -t peacemirrorbot .
docker run -d --env-file .env peacemirrorbot
```
