# 🕊️ PeaceMirorBot (Бот-Миротворец для Telegram)

**PeaceMirorBot** — Telegram-бот для автоматического урегулирования конфликтов в группах, предотвращения ссор, фильтрации мата и оскорблений с помощью системы предупреждений и временных **мутов (режима чтения)**.

---

## 🌟 Ключевые возможности

1. **Эскалация наказаний (Mute Ladder)** — значения настраиваются в `.env`:
   - **1-е нарушение**: Предупреждение в чате с призывом к мирному общению.
   - **2-е нарушение**: Удаление сообщения + **мут на 5 минут** (режим чтения).
   - **3-е нарушение**: Удаление сообщения + **мут на 15 минут**.
   - **4-е нарушение**: Удаление сообщения + **мут на 2 часа**.
   - **5-е и далее**: **мут на 24 часа** с удвоением на каждом следующем нарушении.
2. **Умный детектор мата и обхода фильтров**:
   - Нормализация похожих символов и leet-speak (`cuka` → `сука`, `6лядь` → `блядь`).
   - Сворачивание повторов (`хххуууй` → `хуй`) и склейка разделителей (`х.у.й`, `х у й`).
   - Корни мата ищутся только с начала слова или после приставки, поэтому «хлеба»,
     «требую», «волшебный», «Херсон», «парикмахер» не считаются нарушением.
   - Чисто латинские слова проверяются по отдельному транслит-списку (`eBay`, `xerox` — не мат).
   - Белый список (`/addsafeword`) и кастомный стоп-лист (`/addword`) — **свои у каждого
     чата**: настройки одной группы не влияют на остальные.
3. **Капча для новых участников**: кнопка «Я человек», 3 минуты на подтверждение,
   через 24 часа непроверенный участник кикается (состояние в SQLite, переживает рестарт).
4. **ИИ-помощник «Мирчик»** (Groq Llama 3.3 + фолбэк Mistral): `/ai`, ответы по обращению
   к боту, расшифровка голосовых (Whisper), `/summary` — сводка дня, веб-поиск по запросу.
5. **Репутация и рейтинг**: баллы за спокойное общение и благодарности, `/top` и звания.
6. **Миротворческие инструменты**: `/report`, `/rules`, `/mystats`, умная маршрутизация
   уведомлений активным админам с эскалацией через 5 минут.
7. **Фоновая автоматика**:
   - Восстановление прав после окончания срока мута (с учётом настроек чата).
   - Сброс устаревших предупреждений через 7 дней вежливого поведения.
   - Возобновление активного мута, если нарушитель перезашёл в чат.

## 🛠️ Команды бота

### Для участников:
- `/start` — Приветствие и описание бота.
- `/help` — Справка по командам.
- `/rules` — Правила мирного общения в чате.
- `/mystats` — Своя статистика нарушений, репутация и звание.
- `/top` (`/peacetop`) — Рейтинг Топ-10 миротворцев чата.
- `/report` — *(ответом на сообщение)* Отправить жалобу администраторам.
- `/ai <вопрос>` (`/bot`) — Задать вопрос ИИ-помощнику Мирчику.
- `/summary` (`/digest`) — Краткая сводка сегодняшнего общения.
- `/meme` — Случайный мем.

### Для администраторов:
- `/mute <минуты> <@ник|ID> <причина>` — Мут участнику *(или ответом на сообщение)*.
- `/unmute <@ник|ID>` — Снять мут; далее участник подтверждает капчу.
- `/warn <@ник|ID> <причина>` — Выдать предупреждение.
- `/addword`, `/removeword`, `/wordlist` — Стоп-лист этого чата.
- `/addsafeword`, `/removesafeword`, `/safewordlist` — Разрешённые слова этого чата
  (мат занести нельзя).

> Списки слов привязаны к чату, поэтому эти команды работают только внутри группы —
> в личке с ботом непонятно, какому чату принадлежало бы слово. При обновлении со старой
> версии глобальные списки автоматически копируются во все чаты, которые бот уже знает.
- `/resetstats <@ник|ID|all>` — Сбросить статистику нарушений.
- `/uncaptcha <@ник|ID>` — Снять капчу с участника.

> Команды управления работают только в группе. В личке боту доступен лишь владелец
> из `ADMIN_ID` — иначе любой желающий мог бы править общие списки слов.

## 🚀 Быстрый запуск

### 1. Требования
- Python 3.11+
- Зависимости: см. `requirements.txt` (`python-telegram-bot[job-queue]`, `aiosqlite`,
  `python-dotenv`, `groq`, `ddgs`, `httpx`).

### 2. Настройка `.env`
Создайте файл `.env` (на основе `.env.example`):
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=123456789
DB_PATH=peacemirror_database.db
MUTE_STEP_2_MINUTES=5
MUTE_STEP_3_MINUTES=15
MUTE_STEP_4_MINUTES=120
MUTE_STEP_5_MINUTES=1440
RESET_INACTIVE_DAYS=7
GROQ_API_KEY=gsk_...
MISTRAL_API_KEY=...
```

### 3. Локальный запуск
```bash
pip install -r requirements.txt
python bot.py
```

### 4. Тесты
```bash
python -m unittest test_conflict_detector -v
```

### 5. Продакшен: PythonAnywhere

Бот живёт на бесплатном аккаунте PythonAnywhere (`smmisha`), где **always-on tasks
недоступны**, поэтому он запускается вручную из Bash-консоли через `nohup` и держится
до тех пор, пока жива консоль. Консоль называется `@PeaceMirorBot`, рабочая папка —
`~/PeaceMirorBot`.

Запуск:
```bash
cd ~/PeaceMirorBot
nohup python3 bot.py > bot.log 2>&1 &
```

Обновление до свежего кода (остановить → подтянуть → запустить заново):
```bash
cd ~/PeaceMirorBot
kill $(pgrep -f "python3 bot.py")
git pull origin main
nohup python3 bot.py > bot.log 2>&1 &
tail -n 20 bot.log      # ожидаем "Bot authenticated as @PeaceMirorBot" и "Application started"
```

#### Как понять, что бот жив

Успешные обращения к Telegram намеренно не логируются: `httpx` писал в каждой строке
полный URL с токеном, поэтому его уровень поднят до WARNING. Из-за этого у спокойного
чата лог молчит часами, и тишина сама по себе ничего не говорит.

Признак жизни — строка **HEARTBEAT**, она пишется раз в 5 минут:
```
2026-07-28 12:15:12 - PeaceMirorBot - INFO - HEARTBEAT: бот жив | аптайм 1 мин | сообщений обработано: 0 | активных чатов: 0
```
Свежий HEARTBEAT — бот работает. Строка перестала обновляться — упал.

Смотреть лог живьём (как при запуске в переднем плане):
```bash
tail -f bot.log
```
`Ctrl+C` завершает только просмотр — процесс бота отвязан через `nohup` и продолжает
работать. Быстрая проверка без чтения лога:
```bash
pgrep -af "python3 bot.py"      # есть PID — значит жив
```

Что важно помнить:

- **Только один экземпляр.** Telegram отдаёт `409 Conflict: terminated by other getUpdates
  request`, если бот параллельно запущен где-то ещё (например, локально). Перед локальным
  запуском останавливайте продакшен — иначе оба инстанса дерутся за очередь обновлений,
  а старт с `drop_pending_updates=True` отбросит накопившиеся апдейты.
- **Консоль умирает — умирает бот.** PythonAnywhere прибивает консоли при перезагрузке
  серверов и после долгого простоя; автоперезапуска нет, нужно зайти и поднять руками.
  Непрерывная работа — это платный тариф с always-on task.
- **CPU-квота.** При исчерпании квоты аккаунт уходит в tarpit: бот продолжает работать,
  но ответы ИИ и расшифровка голосовых заметно замедляются.
- **Прокси PythonAnywhere иногда отдаёт 503.** Весь исходящий трафик бесплатного
  аккаунта идёт через `proxy.server:3128`, и он периодически флапает. Проявляется как
  `httpx.ProxyError: 503 Service Unavailable`: на старте — падением процесса (`Exit 1`,
  помогает повторный запуск), во время работы — разовой ошибкой в логе, после которой
  PTB сам продолжает опрос. Косметические вызовы вроде индикатора «печатает…» вынесены
  в `telegram_utils.send_chat_action_safe`, чтобы такой сбой не съедал ответ целиком.
- **`bot.log` перетирается** при каждом запуске (`>`), историю за прошлый прогон
  сохраняйте отдельно, если она нужна.
- Миграции схемы БД применяются автоматически при старте в `init_db`, руками
  ничего делать не надо.
